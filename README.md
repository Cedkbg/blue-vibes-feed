# Ced Lite

**Ced Lite** — Partagez vos moments, connectez-vous avec vos amis, et découvrez du contenu incroyable.

## 🚀 Fonctionnalités

- 📸 Partage de photos et vidéos
- 💬 Messagerie instantanée
- 📞 Appels audio et vidéo
- 🔴 Diffusion en direct (Live)
- 👥 Groupes et communautés
- 📰 Fil d'actualités
- 🔔 Notifications en temps réel
- 🔒 Authentification sécurisée

## 🛠 Technologies

- React + TypeScript
- Vite
- Tailwind CSS
- Lovable Cloud (Backend)
